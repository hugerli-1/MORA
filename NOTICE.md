# Distribution Notes

This is an anonymous peer-review code package for MORA. Author identities,
institutional metadata, Git history, local run paths, datasets, and backbone
checkpoints are intentionally not included.

The package does not vendor third-party backbone implementations. Obtain them
from their authors and retain the applicable upstream copyright and license
notices. Dataset and checkpoint redistribution rights are not conveyed by this
package.

A permanent software license has not been selected for this review snapshot.
The authors should choose and add their intended license before a public,
non-anonymous software release.
